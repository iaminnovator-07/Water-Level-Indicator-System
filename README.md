🚀 Overview
━━━━━━━━━━━━━━━━━━

Water Level Indicator System was developed as an early embedded systems project focused on understanding liquid level sensing, automation logic and monitoring systems.

The project detects water levels and provides indication alerts using LEDs and sensor inputs.

⚙ Working Principle
━━━━━━━━━━━━━━━━━━

The system uses a water level sensor to detect liquid height inside a container.

Based on the detected level:
• LEDs indicate water status  
• Higher water levels activate additional indicators

The project demonstrates basic liquid monitoring and automation principles using embedded systems.
