# Project Report — Water Level Indicator System

## Introduction

The Water Level Indicator System is an Arduino-based monitoring prototype designed to detect and indicate water levels using sensors and LEDs.

## Aim

To develop a basic water monitoring system capable of providing level indication and alert functionality.

## Components Used

- Arduino UNO
- Water Level Sensor
- LEDs
- Breadboard
- Jumper Wires

## Applications

- Water tank monitoring
- Smart homes
- Industrial liquid monitoring
- Embedded systems learning

## Conclusion

The project successfully demonstrated liquid level sensing and embedded monitoring concepts using Arduino.
